# TS-Kit Monad

[![TypeScript](https://img.shields.io/badge/TypeScript-5.0+-blue.svg)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

A lightweight, robust, zero-dependency utility library bringing functional error handling (`Result<T, E>`), nullable container primitives (`Option<T>`), and battle-tested asynchronous combinators to TypeScript.

## Why use ts-kit-monad?
- **No Thrown Exceptions**: Handle expected failures explicitly in the type system without `try/catch` ambiguity.
- **Zero External Dependencies**: Ultra-lean bundle size (< 2KB gzipped).
- **Full TypeScript Type Inference**: Strict compiler checks prevent unhandled errors.

## Installation
```bash
npm install @kelvin/ts-kit-monad
```
